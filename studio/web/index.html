A real local workflow.

This HTML is the design and behavior reference for the Android app. The included local runner uses FFmpeg to create real files on your computer.

python server.py

Python 3.10+, FFmpeg, and FFprobe must be on PATH. The runner opens the app at http://127.0.0.1:8765.

Opening the standalone HTML directly allows previews and settings, but not encoding. Direct HTTP(S) media URLs require the runner. Webpages, HLS/DASH, live streams, and HDR video export are outside this slice.

No native Android code or APK is changed by this workbench. Its job model maps to the app’s on-device FFmpeg engine.
