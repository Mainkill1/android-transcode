# Movies SDR Main 10 conversion fix

The user's 3,675,467,709-byte HEVC Main 10 MKV in `Movies` failed before encoding because the planner blocked every format above 8 bits. Android's `MediaExtractor` also omitted its E-AC-3 5.1-channel track, so the editor showed incomplete source information. The failed job and its settings remain in the persisted queue.

Native-enabled builds now inspect document-provider media with FFprobe through [FFmpegKit's SAF protocol](https://github.com/arthenica/ffmpeg-kit/wiki/Storage-Access-Framework), then release the registered SAF URL. Inspection leaves the multi-gigabyte original in place. If a provider omits its byte count, that count stays unknown until staging; a SAF URL is not mistaken for a zero-byte local file. The planner accepts the narrow `yuv420p10le` case (up to 10 bits, absent/BT.709 transfer, primaries and matrix, and no HDR side metadata) and explicitly emits `format=yuv420p` for the 8-bit output. Untagged Main 10 is treated as SDR for this path; source metadata alone cannot prove its intended color. PQ/HLG HDR and other unqualified formats still stop with a color-pipeline error, while output verification independently rejects high-bit-depth video.

The failed item appears first under **Queue · 1 failed**, with its saved reason and target size visible. **Add retry to queue** copies its saved settings into a new queued job; **Convert queued files** starts the queue. The old failed record is kept for diagnosis.

Device qualification on the full `Movies` document confirmed one 1920×1080 video track, one six-channel 48 kHz audio track, full duration, and no explicit HDR metadata without copying the file for inspection. A five-second excerpt using the original failed job's stale source snapshot and saved conversion settings was staged and converted through the production transcoder to a verified 1280×720 H.264/AAC output below 1.5 MB. This exercises the renderer's re-probe before mapping audio. The saved queue was byte-identical before and after testing; the temporary excerpt and staging directory were removed. The complete three-hour export has not been run.
