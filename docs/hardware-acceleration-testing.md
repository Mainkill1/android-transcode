# Android acceleration testing

Start with [Runtime codec trials](runtime-codec-trials.md) for the implementation,
production fallback rules, test isolation and exact build/ADB commands.

Inventory reports describe advertised components only. Native runtime reports
exercise the production preparer, retry executor and output verifier. Neither is
full physical-device qualification or an equal-quality speed benchmark.

No test helper, receiver or command server is included in the production app.
