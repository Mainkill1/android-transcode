# FFprobe cancellation qualification

The pinned FFmpegKitNext wrapper at `5e51b2da4c3593c0f2f9b49f53eeb497d93e39d3` did not inspect its native session cancellation map in FFprobe's frame-reading loop. The source-build helper now temporarily applies `tools/patch_ffprobe_cancel.py`, which handles cancellation before native start, interrupts FFprobe reads, and reports cancellation with return code 255. The checkout is restored after building. The Kotlin adapter waits for the native completion callback before the managed bridge releases its lock or callers remove staged files.

On 2026-09-29, a direct arm64 build with NDK r28.2, x264/x265/libvpx/SVT-AV1/dav1d/MediaCodec/WebP/zlib, 16 KB linker flags, the static C++ patch from #11, and the FFprobe cancellation patch produced an AAR with SHA-256 `09bd962f7d3ad66b9bc29c2df67681b55b6dc6c2472135d48490e94ea51a7d3a`. The PR6 lab APK SHA-256 was `a4b32622b2139890f39956adafda528070098290da08bb10fecb4be93a962f9a`. Both passed `tools/verify_android_native.py --require-abi arm64-v8a`; this checks native payload and 16 KB ELF/APK alignment, not behavior on a 16 KB-page device.

The OnePlus 9 Pro LE2125, Android API 36, at `10.0.0.56:38477` passed `NativeProbeCancellationTest` (3/3) on the aligned PR6 rebuild. Its four-hour, 600,000-frame FLAC fixture remained in the isolated `dev.forma.transcode.lab.codec` private files. The first two tests cancel a probe before native start and a live `-count_frames` scan, wait for native cancellation, then successfully probe again. The third drives a real `FfmpegTranscoder` job through `RunCoordinator`: after a synthetic codec-init rejection, fixture-copy encode and pre-scan decode, Stop interrupts the real native verification scan, prevents publication and further routes, preserves the source, and allows a later one-second AAC job with real native encode and decode to complete. The synthetic steps isolate the long verification phase; they do not qualify an actual device encoder or full decode of the long fixture. Raw output is in ignored PR6 `app/build/device-evidence/ffprobe-cancel-worker-instrument.log`.

Host `ExportRetryChecks` additionally hold the candidate during simulated verification cancellation, check that no fallback or later fit attempt starts after Stop, and run a subsequent attempt after native completion. A full `TranscodeService` queue Stop and physical power-policy test on this exact artifact remain to be run before claiming end-to-end qualification of those paths.
